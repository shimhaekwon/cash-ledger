# 💰 현금 출납부

모바일-first PWA 기반 현금 거래 관리 앱

## 🎯 주요 기능

- ✅ 입금/출금 거래 등록
- ✅ 분류1, 분류2, 분류3 지원 (수정 시 추가)
- ✅ 실시간 잔액 표시
- ✅ 분류별 지출 통계
- ✅ 월별 거래 필터
- ✅ CSV 내보내기 (엑셀 호환)
- ✅ 백업/복원
- ✅ localStorage 저장 (브라우저 종료해도 유지)

## 📁 파일 구조

```
├── index.html    # 메인 화면
├── app.js        # 앱 로직
├── styles.css    # CSS 스타일

└── README.md     # 이 파일
```

## 📱 사용법

1. 파일 열기: `index.html`
2. 입금/출금 선택 → 금액 입력 → 분류 선택 → 저장
3. 거래 수정 시 분류2, 분류3도 추가 가능

## 🛠️ 기술

- Vanilla JS
- localStorage
- Puppeteer 테스트

## ⚠️ 데이터 유실 주의사항

**아래의 경우 데이터가 삭제됩니다. 정기적으로 백업하세요.**

| 상황 | 설명 | 대처법 |
|------|------|--------|
| **브라우저 데이터 삭제** | 설정 →隐私에서 캐시/데이터 삭제 시 localStorage 삭제됨 | 주기적 백업 |
| **개인정보 청소** | Chrome "시간대별 삭제"로 전체 또는 사이트 데이터 삭제 시 | 백업 파일 보관 |
| **시크릿/프라이빗 모드** | guest/incognito 모드는 종료 시 데이터 삭제됨 | 일반 모드 사용 |
| **쿠키 차단** | 브라우저 설정에서 쿠키/저장소 차단을 선택 시 | 설정 변경 필요 |
| **스토리지 용량 초과** | 브라우저 스토리지 제한 초과 시 데이터 삭제 가능 | 불필요한 데이터 삭제 |
| **앱 초기화** | 하단 "삭제" 버튼 2번 클릭 시 전체 데이터 삭제 | 확인 다이얼로그 2번 수락 필요 |

### ✅ 안전하게 데이터 유지하는 방법

1. **주기적 백업**: 하단 `💾 백업` 버튼으로 JSON 파일 다운로드
2. **다른 브라우저/기기 동기화**: Chrome 로그인 → 다른 기기에서 localStorage 동기화
3. **PC 데이터 확인**: 개발자도구(F12) → Application → Storage → Local Storage에서 확인

### 📋 데이터 복원

1. `📂 복원` 버튼 클릭
2. 이전에 다운로드한 `.json` 백업 파일 선택
3. 확인 대화상자에서 "확인" 클릭
